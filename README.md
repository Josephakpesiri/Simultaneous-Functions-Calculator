# Simultaneous-Functions-Calculator
🎯 YOUR TASK

Write THREE separate Python functions:

1️⃣ BMI Calculator

Create a function that calculates Body Mass Index (BMI) using weight and height.

Formula:

BMI = weight / (height × height)

Use weight in kilograms and height in metres.

2️⃣ Rectangle Area Calculator

Create a function that calculates the area of a rectangle.

Formula:

Area = length × width

3️⃣ Celsius to Fahrenheit Converter

Create a function that converts a temperature from Celsius to Fahrenheit.

Formula:

Fahrenheit = (Celsius × 9/5) + 32

⚠️ IMPORTANT REQUIREMENTS

* Each calculation must have its own function.
* Each function MUST use return to send back its result.
* Do NOT use print() inside the functions to display the results.
* Call each function and use print() outside the functions to display the returned results.
* Use meaningful function and variable names.
